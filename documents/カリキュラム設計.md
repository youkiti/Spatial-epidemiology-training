## 1. 3段階の骨格

教材全体の出発点であり、最初に教える「型」。`docs/memo.md` 冒頭(2〜9節)と `CLAUDE.md` の表に一次資料がある。

|---|---|---|

### 章1: 記述 — どこで多い?

- **段階**: 1(記述)
- **学習目標**:
  1. 患者数(count)をそのまま地図にすることの問題点を説明できる
  2. 累積罹患割合・有病割合・死亡率を地域単位で計算できる
  3. 年齢構成が地域間で異なる場合に標準化割合が必要な理由を説明できる
  4. SIR/SMR(観察数と期待数の比)の意味を説明できる(SIR = 1.5 は「期待値の1.5倍」)
  5. choropleth map の作り方と、色分けの区切り(階級区分)が与える印象の違いに注意できる
- **扱う概念**: 累積罹患割合・有病割合・死亡率、年齢標準化割合、SIR/SMR、choropleth map、分母(人口)の重要性
- **クイズ**: 自己チェック3問、章末クイズ10問(8割合格)

### 章2: 空間重み行列 — 「隣」を先に決める

- **段階**: 1→2の橋渡し(空間統計を始める前の準備)
- **学習目標**:
  1. 通常の統計にはない発想として、「A地域の隣はどこか」を先に定義する必要性を説明できる
  2. queen contiguity(境界を共有すれば隣)の定義を説明できる
  3. 距離閾値による近接定義(例: 50km以内は隣)を説明できる
  4. 隣接定義を変えると分析結果が変わりうることを理解する(章6「隣の定義の事後決定」の伏線)
- **扱う概念**: spatial weights matrix(空間重み行列)、queen contiguity、距離閾値、隣接定義が結果に与える影響
- **クイズ**: 自己チェック3問、章末クイズ10問(8割合格)
- 備考: memo.md 9節「隣をどう決めるの?」が一次資料。チェスのクイーンが縦・横・斜めに動けるという比喩(memo.md)をそのまま踏襲する。

### 章3: Global Moran's I — 全体として偏っている?

- **段階**: 2(パターン)
- **学習目標**:
  1. 空間的自己相関(spatial autocorrelation)とは何かを、正の自己相関・負の自己相関の両方を例に説明できる
  2. Global Moran's I が「地図全体として似た地域が集まっているか」を測る指標であることを説明できる
  3. Moran's I の符号(プラス/ランダム付近/マイナス)の解釈を説明できる
  4. permutation test(値をシャッフルして偶然の集まり方と比較する)による有意性検定の考え方を説明できる
  5. Global Moran's I だけでは「どこが集まっているか」は分からないという限界を説明できる(章4への橋渡し)
- **扱う概念**: 空間的自己相関、Global Moran's I、permutation test、Global指標の限界
- **クイズ**: 自己チェック3問、章末クイズ10問(8割合格)
- **実例論文**: Pradhan P, Iyer HS, Rebbeck TR. *JAMA Netw Open.* 2025;8:e2537905(米国3,142 counties のがん検診研究)を、queen contiguity → Global Moran's I という手順の実例として導入する(§5 の注記に従い、具体的な統計値はこの文書に書かない)。

### 章4: LISA / Gi\* / SaTScan の違い ★教材の山場

- **段階**: 2(パターン)
- **学習目標**:
  1. Local Moran's I(LISA)が「自分の値」と「周囲の値」の組み合わせを High-High / Low-Low / High-Low / Low-High の4種類に分類する手法であることを説明できる
  2. Getis-Ord Gi\* が「高い値・低い値の“塊”」(hot spot / cold spot)を探す手法であり、LISA のような4分類は行わないことを説明できる
  3. **「値が高い」ことと「hot spot である」ことは別**であることを、具体的な数値グリッドを使って説明できる(下記の数値例)
  4. spatial scan statistic(SaTScan)が「地図上を様々な大きさの窓で走査し、異常に患者が多い地理的範囲を探す」手法であり、LISA/Gi\* とは検出の発想自体が異なることを説明できる
  5. LISA の High-Low(空間的アウトライヤー)と、Gi\* の hot spot の違いを説明できる
- **扱う概念**: LISA(High-High/Low-Low/High-Low/Low-High)、Getis-Ord Gi\*(hot spot/cold spot)、spatial scan statistic、空間的アウトライヤー
- **数値グリッドの具体例**(memo.md 647〜871行目が一次資料。教材本文でもこの数値をそのまま、または同型の数値で再現する):
  - **hot spot の例**(周囲もまとまって高い):
    ```
    10 11 10
    11 12 11
    10 11 10
    ```
    このグリッドは Gi\* では典型的な hot spot として検出される。中央の12だけが突出しているわけではなく、周囲を含めて全体が高いことが条件。
  - **空間的アウトライヤーの例**(自分だけ高く、周囲は低い):
    ```
     2  2  2
     2 20  2
     2  2  2
    ```
    中央の20は明らかに「値が高い」地域だが、周囲は低いため Gi\* では hot spot になりにくい。LISA ではこれを **High-Low**(空間的アウトライヤー)として明示的に検出できる。この対比が「値が高い」≠「hot spot」の核心。
  - この2つのグリッドを並べて提示し、「同じ“真ん中が高い”状況でも、周囲がどうかによって Gi\*/LISA の判定が変わる」ことをクイズの設問(章末クイズ)でも問う。
- **クイズ**: 自己チェック3問、章末クイズ**12問(10問以上で合格)**。他章より厚くする理由は §2 冒頭の共通仕様を参照。
- **実例論文**: 章3から続けて Pradhan P, et al. 2025 の Global → Local の対比(Global Moran's I の低下と、それでも一部地域に LISA クラスターが残る、という構造)を使う。統計値は本文書に書かない(§5)。

### 章5: 説明 — なぜそこに多い?

- **段階**: 3(説明)
- **学習目標**:
  1. 通常の回帰分析が「隣接地域どうしが似ている」という空間的な依存性を無視してしまう問題を説明できる
  2. spatial regression(空間回帰)が何を追加で考慮するかを説明できる
  3. areal data(地域集計データ)に対する Poisson regression + CAR(Conditional Autoregressive)モデルの考え方を説明できる
  4. BYM(Besag-York-Mollié)モデルが何を組み合わせたモデルかを説明できる(空間相関成分+非構造化誤差成分)
  5. 小地域で患者数が少ないことによる割合の不安定さを、Bayesian smoothing がどう安定化するかを説明できる
- **扱う概念**: spatial regression、CAR モデル、BYM モデル、Bayesian smoothing
- **クイズ**: 自己チェック3問、章末クイズ10問(8割合格)
- **実例論文**: Blazel MM, et al. *JAMA Netw Open.* 2024;7:e2429764(高血圧、地域の社会経済的不利と有病割合)を、「地図で発見 → Moran's I で確認 → CAR モデルで説明」という一連の流れの実例として導入する。統計値は本文書に書かない(§5)。

### 章6: 初学者が注意する5つの落とし穴

- **段階**: 全段階を通した注意点(まとめ)
- **学習目標**:
  1. 人口の多さを無視した分子だけの地図がなぜ誤りかを、具体例で説明できる([要件定義書](要件定義書.md) §1.3 原則6・§4.2 で扱う専門医名簿の実例に接続する)
  2. 小地域の少数例による割合の不安定さを説明できる(章5の Bayesian smoothing と接続)
  3. MAUP(Modifiable Areal Unit Problem、地域単位を変えると結果が変わる問題)を説明できる
  4. 地域レベルの関連を個人の因果関係と取り違える誤り(生態学的誤謬)を説明できる
  5. 「隣」の定義(空間重み行列)を分析後に都合よく選び直すことの問題(事後決定)を説明できる(章2への接続)
- **扱う概念**: 人口の無視、小地域の少数例、MAUP、生態学的誤謬、隣接定義の事後決定
- **クイズ**: 自己チェック3問、章末クイズ10問(8割合格)
- 備考: この章はハンズオン③(MAUP実演、§4)と対になる。都道府県 vs 二次医療圏で同じ分析をして結果が変わることを、この章の MAUP の説明の直後に体験させる導線にする。

## 4. Rハンズオン: 本編3本+ケーススタディ資料

issue #17〜#20 に対応する。issue #17 は Rmd レンダリング配管(Rmd → md + 図 → docs/)であり、個別のハンズオンではなく、以下のハンズオンを公開ページへ実際に反映するための実行基盤にあたる。ハンズオン本体は issue #18〜#20 の3本で、すべて実装済み・main にマージ済みである。

**当初 v0.1 で構想していたハンズオン④(統合ケーススタディ)は、対応する issue を起票しないまま公開範囲から外した。** その代わり、②③が使う実データが何を数えていて何を数えていないかをまとめた**資料ページ**を `docs/handson/04-case-study.md` として公開する(下記 §4.4)。3段階の型そのものは①〜③が段階ごとに扱っており、実データでの一気通貫の再演は、教材としての追加価値に対して維持コスト(名簿の改訂ごとの再レンダリングと数値の再検証)が見合わないと判断した。

### ハンズオン①: 地図 → Global Moran's I → LISA → Gi\*(issue #18)

- **対応章**: 章1〜4
- **データ**: 架空の10市町村データ(§5 の役割分担どおり、概念導入用)
- **流れ**: memo.md 末尾の提案をそのまま踏襲する。①choropleth map を描く → ②Global Moran's I を計算する → ③LISA map を描く → ④Gi\* map を描く。章4の数値グリッド例(§2 章4参照)と対応する架空データを設計し、「値が高い」と「hot spot」の違いを実際に手を動かして再現できるようにする。
- **使用パッケージ**: `sf`, `spdep`, `ggplot2`(いずれも [要件定義書](要件定義書.md) §5.3 で導入済み。追加インストール不要)

### ハンズオン②: CAR/BYM(issue #19)

- **対応章**: 章5
- **データ**: 架空の10市町村データの延長、またはやや大きい架空データ(小地域の少数例による不安定さを見せるため、人口・患者数にばらつきを持たせたデータを新規に設計する必要がある可能性がある。データ設計は issue #19 の担当とする)
- **流れ**: 通常の Poisson 回帰 → 空間相関を無視した場合の問題点の提示 → CAR Poisson モデル → BYM モデルとの比較
- **使用パッケージ**: `spatialreg`(導入済み)に加えて **`CARBayes`(issue #19 で確定)**。`INLA` は CRAN ではなく専用リポジトリからの導入で読者に要求するハードルが高いため採用せず、章5で違いに触れるにとどめた

### ハンズオン③: MAUP の実演(都道府県 vs 二次医療圏)(issue #20)

- **対応章**: 章6(および章2の「隣の定義」の伏線回収)
- **データ**: **感染症専門医名簿の実データで実装した**(v0.1 では「架空データでの実演を基本とし、実データでの再確認はハンズオン④に譲る」としていたが、ハンズオン④を公開範囲から外したため、実データでの実演はこのハンズオン③が担う)。同じ分析を都道府県単位と二次医療圏単位の両方で行い、**結果(Moran's I の値や地図の見え方、LISA/Gi\* の判定)が変わることを見せる**。分子の定義(care/all/official)を変える感度も併せて示し、単位の効果と分子定義の効果が別の軸であることを扱う。
- **流れ**: 同一の元データ(市区町村レベルなど細かい単位)を都道府県単位・二次医療圏単位のそれぞれに集計し直し、choropleth map と Global Moran's I を両方の単位で計算して比較する。

### 4.4 資料: ケーススタディのデータ(`docs/handson/04-case-study.md`)

**ハンズオンではなく資料ページである。** コードを実行するページではなく、②③が使う実データの前提条件を開示する。

- **対応章**: 章1(分母)・章6(落とし穴)の実データ側の裏づけ
- **データ**: 感染症専門医名簿(実データ)。[要件定義書](要件定義書.md) §4.2 の方針(生データ非コミット、加工コードと出力図表のみ保持、人口10万対専門医数を基本指標とする)に従う。
- **内容**: (a)「診療の場のみ(`care`、主系列)」と「勤務地ベース(`all`)」の2系列があり、どちらを数えるかで339区域中11区域の値が変わる(丹南・高幡は0名↔1名でカテゴリ自体が変わる)、(b) 二次医療圏レベルの分子は名簿1,894名のうち1,626名(85.9%)しか地図に載らず、その内訳、(c) 欠測が地図の模様を作っていないことの検算(割付率と専門医密度の Spearman ρ = −0.1134)、(d) 大学名だけの記載を人手の推論で補っており `data/curated/facility_crosswalk.csv` に記録していること。
- **v0.1 からの変更**: 当初は「①集計 → ②人口10万対専門医数の地図 → ③Global Moran's I → ④LISA/Gi\* → ⑤CAR」を実データで通しで実践する統合ハンズオンとして構想していたが、その型は①〜③が段階ごとに扱うこととし、このページは実データ側の前提条件の開示に役割を絞った。

## 5. 実例論文・総説の扱いと裏取りの注記

**重要な注記**: `docs/memo.md` 中の統計値(Moran's I の具体的な値、prevalence ratio 等)・論文の書誌情報は対話ログ由来である。**一次資料での裏取りは issue #16 で完了した(2026-08-18)。確認した数値・原文の該当箇所・書誌情報は [引用検証.md](引用検証.md) に記録してある。**

本文書(カリキュラム設計)は引き続き**具体的な統計値を記載しない**。§2 の章3・章4・章5で各論文を「どの手順の実例として使うか」という構造(手法の並び順)のみを述べる方針は変えない。数値の正本は [引用検証.md](引用検証.md) であり、教材本文(`docs/concepts/`)への反映もそこから行う。**引用検証.md に載っていない数値を教材本文に書かない。**

裏取りで判明した、教材の記述に影響する2点:
