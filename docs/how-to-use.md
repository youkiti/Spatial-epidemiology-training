# 使い方

## 読み進め方

概念パート(全6章)は、章1から章6まで順番に読み進める構成です。章2「空間重み行列」は章1(記述)と章3以降(空間統計)の橋渡しにあたり、章4「LISA / Gi\* / SaTScan の違い」がこの教材の山場です。Rハンズオンは対応する概念パートの章を読んだあとに取り組むと理解しやすい構成にしています。

## クイズの位置づけ

各章には2種類のクイズがあります。

- **自己チェッククイズ**(各章3問) — 合否を記録しません。章の途中でその場の理解を確認するためのものです。
- **章末クイズ**(各章10問、正答率8割以上で合格。章4のみ12問、10問以上で合格) — 合否を記録します。四択・一括採点で、不正解だった設問には解説が表示されます。

## 学習記録について

クイズの正誤・合否状態は、**お使いの端末のブラウザの localStorage にのみ保存されます。** サーバーには送信されません。本サイトはアクセス解析を含む一切のユーザーログを収集しない方針で運用しています。別の端末やブラウザで開くと、学習記録は引き継がれません。

## Rハンズオンの動かし方

Rハンズオンは R Markdown(Rmd)で書かれ、実行結果をあらかじめレンダリングした状態で公開しています。ページを読むだけでも内容は追えますが、手元で再現する場合は次の環境を用意してください。

- **R**: 4.5.2 で動作確認
- 必要な R パッケージ: `sf`, `spdep`, `ggplot2`, `dplyr`, `rmarkdown`, `knitr` に加え、ハンズオン②(CAR/BYM)では `spatialreg` と `CARBayes`(または `INLA`)が必要です。パッケージの詳細な一覧は各ハンズオンページに記載します。

```bash
Rscript -e 'rmarkdown::render("path/to/file.Rmd")'
```
