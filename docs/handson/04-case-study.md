# 資料: ケーススタディのデータ(感染症専門医の地域偏在)

このページは、**ハンズオン②(CAR/BYM)と③(MAUP の実演)が使う実データ** — 日本感染症学会の専門医名簿から作った二次医療圏別・都道府県別の専門医数 — について、**そのデータが何を数えていて、何を数えられていないか**をまとめた資料です。コードを動かすページではありません(手を動かす本編は[①](01-map-moran-lisa-gi.md)〜[③](03-maup.md)です)。

分析に入る前にここを読んでおくと、②③で出てくる地図や推定値を「どこまで信じてよい数字か」を判断しながら読めます。**分子の欠測と、「何を専門医として数えるか」の定義**という2つの論点は、実データを扱う限り避けて通れないものであり、教材本文よりもここで正面から扱っています。

!!! note "このページの位置づけ"

    「①集計 → ②率の地図 → ③Global Moran's I → ④LISA/Gi\* → ⑤CAR」を実データで一気通貫にやり直す統合ハンズオンは、今回の公開範囲には含めていません。その型は[①](01-map-moran-lisa-gi.md)〜[③](03-maup.md)が段階ごとに扱っており、このページはその**実データ側の前提条件**を引き受けます。

## データの制約

このケーススタディが使う二次医療圏レベルの分子には、地域単位のデータを扱うときに必ず向き合うことになる欠測があります。加えて、専門医名簿の勤務先には診療を行わない場所も含まれるため、「何を数えるか」を変えると地図そのものが変わります。ここで先に開示しておきます。

### 「診療の場」と「勤務地」で2通りの分布がある

専門医名簿には、国立健康危機管理研究機構 国立感染症研究所や保健所、製薬企業などが勤務先として記載されている行があります。これらに所属する医師は専門医ではありますが、**その医療圏の住民が実際に受診できる先ではありません。** 研究所や保健所を病院と同じように地図に載せてしまうと、「その地域に専門医による診療へのアクセスがある」という地図本来の趣旨から外れてしまいます。

そこでこの教材では、名簿の各行に「診療の場かどうか」を示すフラグ(`care_setting`)を立て、除外するのではなく**2通りの分布を並べて出す**設計にしています。

- **診療の場のみ(`care`、主系列)**: 病院・診療所など、住民が実際に受診できる場所にいる専門医だけを数えた分布。この教材が既定で使う地図はこちらです。
- **勤務地ベース(`all` = `care` + `non_care`)**: 上記に、研究機関・保健所・製薬企業などの非診療の勤務先を加えた、名簿の勤務地をすべて数えた分布。

2026-08-18実測(全国合計。`data/processed/specialists_iryoken2.csv` の `n_specialists_care` / `n_specialists_all`):

| 系列 | 全国合計 | 割付率(名簿1,894名に対する割合) |
|---|---:|---:|
| 診療の場のみ(`care`、主系列) | 1,626名 | 85.9% |
| 勤務地ベース(`care`+`non_care`) | 1,654名 | 87.3% |

症例定義(何を数えるか)を変えると結果が変わること自体は、空間疫学に固有の問題ではありません。ですが、それを**地図にすると差が視覚的にはっきり見える**のは、地域データを扱う教材ならではの示しやすさです。

差が出るのは339区域中**11区域だけ**ですが、出る場所では小さくありません。2026-08-18実測(`data/processed/specialists_iryoken2.csv` の `n_specialists_care`/`n_specialists_all` と、`data/processed/population_iryoken2.csv` の `population_2020` から再現できます):

| 医療圏 | care | all | 人口10万対(care) | 人口10万対(all) | 変化 |
|---|---:|---:|---:|---:|---:|
| 1304 区西部(東京都) | 69 | 85 | 5.37 | 6.61 | +23.2% |
| 1310 北多摩西部(東京都) | 4 | 5 | 0.61 | 0.76 | +25.0% |
| 3503 周南(山口県) | 1 | 2 | 0.41 | 0.82 | +100% |
| 1803 丹南(福井県) | **0** | **1** | 0.00 | 0.55 | (0名→1名) |
| 3903 高幡(高知県) | **0** | **1** | 0.00 | 1.97 | (0名→1名) |
| 1301 区中央部(東京都) | 92 | 95 | 9.71 | 10.02 | +3.3% |
| 0403 仙台(宮城県) | 25 | 26 | 1.62 | 1.69 | +4.0% |
| 1303 区西南部(東京都) | 25 | 26 | 1.69 | 1.76 | +4.0% |
| 1305 区西北部(東京都) | 31 | 32 | 1.55 | 1.60 | +3.2% |

区西部(東京都)は人口10万対専門医数が5.37から6.61(+23.2%)に上がります。もっと大きいのは**丹南(福井県)と高幡(高知県)で、care系列では専門医0名の医療圏ですが、all系列では1名になります。** これは濃淡の変化ではなく、「専門医がいない医療圏」から「専門医がいる医療圏」へと**カテゴリそのものが変わる**変化です。地図の読み方(色分けの階級)が変わりうるという点で、この教材が最も見せたい効果はここに現れています。

### 二次医療圏レベルだけが欠測を持つ

名簿1,894名のうち、二次医療圏の地図(`care` 系列・主系列)に載ったのは**1,626名(85.9%)**です。載らなかった内訳は次のとおりです(欠測と、上で説明した `non_care` の除外は別の理由なので分けています)。

| 区分 | 人数 | 理由 |
|---|---:|---|
| 未割付 | 163名 | 施設名が公表データ(医療情報ネット・国土数値情報)に見つからない |
| 割付不可(記載なし・国外) | 59名 | 名簿に施設の記載が無い(46名)、または勤務先が国外(13名) |
| 割付不可(非診療勤務先で所在不明) | 16名 | 診療を行わない勤務先で、所在の参照点も特定できない |
| 施設は特定できたが医療圏に載らない | 2名 | 参照点の座標がどの二次医療圏ポリゴンにも入らない(`iryoken2.geojson` は1km²未満の離島リングを除去済み) |
| **欠測の小計** | **240名** | |
| 診療の場にいる専門医(`care`、主系列に載る) | 1,626名 | |
| 非診療の勤務先だが所在は判明(`non_care`、`all` 系列にのみ載る) | 28名 | |

1,626 + 28 + 240 = 1,894 で全数を説明できます。

一方、**都道府県レベルの分子は名簿1ページ目の公式集計(1,903名)を使うので、この欠測を持ちません。** 二次医療圏レベルに集計し直す作業で施設名を突合する必要が生じたことで、初めて欠測が発生しています。同じデータでも集計単位を変えると失われる情報が変わりうる、という点は[章6(落とし穴)](../concepts/ch6-pitfalls.md)の MAUP とは別軸の注意点です。

### 欠測が地図の模様を作っていないか

分子が欠けている地図でまず疑うべきなのは、「欠測しやすい地域」と「値そのもの」が相関し、地図の濃淡が実際の偏在ではなく欠測パターンを映してしまっていないかです。都道府県別に割付率(`care` 系列・主系列)を比べると、最も低いのは富山県(64.3%)で、島根県など複数県で100%でした。この割付率(`care` 系列で実際に地図に載る人数/名簿本体人数)と、人口10万対専門医数(名簿本体ベース)の相関を確認したところ、Spearman ρ = −0.1134 とごく弱く、割付できたかどうかと専門医密度のあいだに目立った関連は見られませんでした。欠測が特定の密度帯に偏っている様子はない、ということです。この値は `python scripts/verify_facility_linkage.py` を実行すると再現できます(条件7として出力されます)。

### 施設単位のデータは公開範囲と再識別に注意が必要

上記の集計の元になっているファイル(`data/processed/specialists_facility.csv`・`facility_geo_audit.csv`)は、都道府県別・二次医療圏別の集計値だけでなく、**施設単位の集計値**も保持しています。氏名は一切含みませんが、施設名は公開されている名簿PDFと突合可能なため、氏名が無いことが個人単位の推定を防ぐわけではありません。公開範囲の考え方と利用上の注意は `data/processed/README.md` にまとめています。

### 大学名だけの記載は推論で補っている

名簿には「長崎大学」のように大学名だけを記載した行があります。これを長崎大学病院に対応づけるような判断は、名簿そのものから直接読み取れるものではなく、**人が行った推論**です。この教材では、そうした推論を1行ずつ根拠つきで `data/curated/facility_crosswalk.csv` に記録し、機械的な突合とは区別して扱っています。地図を見るときは、色の濃淡の裏に「機械的に決まった割付」と「人が補った割付」が混在していることを意識してください。
